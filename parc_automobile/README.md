# Parc Automobile

Ce projet est un système complet de gestion de flotte de véhicules, avec des fonctionnalités d'analyse, de génération de rapports, de visualisation et une interface CLI.

## Structure du projet

- `main.py` : Point d'entrée principal (CLI)
- `generer_donnees_demo.py` : Générateur de données de démonstration (à créer)
- `requirements.txt` : Dépendances Python
- `RAPPORT_TECHNIQUE.md` : Rapport technique (convertir en PDF)
- `QUICKSTART.md` : Guide de démarrage rapide
- `CONVERSION_PDF.md` : Instructions de conversion PDF
- `CHECKLIST_PROJET.md` : Checklist de validation

## Usage
Reportez-vous au fichier QUICKSTART.md pour lancer le projet.
