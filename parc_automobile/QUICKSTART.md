# Quickstart – Parc Automobile

1. Cloner le dépôt
2. Installer les dépendances :
   ```bash
   pip install -r requirements.txt
   ```
3. Lancer le système principal :
   ```bash
   python main.py
   ```
4. Générer des données de démonstration (optionnel)
   ```bash
   python generer_donnees_demo.py
   ```
